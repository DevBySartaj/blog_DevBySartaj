# DevBySartaj - Personal Tech Blog & Portfolio 🚀

Welcome to the official repository of **DevBySartaj**! This is a modern, lightweight, and fully responsive personal tech blog and engineering portfolio website. It showcases deep-tech articles, full-stack applications, low-level systems projects, and custom UI/UX designs.

🌐 **Live URL:** [https://web.app](https://web.app)

---

## 💻 Tech Stack & Tools

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design & UI:** Figma
- **Backend & Cloud:** Firebase Hosting, Bash/Shell scripting
- **Development Environment:** Linux (Ubuntu), Git & GitHub

---

## 📂 Project Structure

```text
├── .firebase/              # Firebase configuration cache
├── assets/                 # Images, icons, and static vectors
├── blogpost/               # Individual blog article pages
├── css/                    # Custom stylesheet files
├── js/                     # Client-side JavaScript functionality
├── 404.html                # Custom error page
├── index.html              # Main landing page & portfolio portal
├── about.html              # Developer profile and background
├── contact.html            # Contact and inquiry form
├── firebase.json           # Firebase deployment configuration
├── .gitignore              # Files to ignore in Git version control
└── README.md               # Project documentation (This file)
```

---

## 📝 Features Implemented

- **Responsive Layout:** Optimized perfectly for Mobile, Tablet, and Desktop screens.
- **Dynamic Content Modules:** Sections highlighting Trending Articles (Firebase, C/C++, System Design).
- **Search System:** Ready to scale custom search workflow for tutorials and courses.
- **Clean Code Architecture:** Structured modular folders for clean maintainability.

---

## 🚀 How to Run Locally

1. **Clone this repository:**
   ```bash
   git clone https://github.com/DevBySartaj/blog_DevBySartaj.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd blog_web
   ```
3. **Open with any local live server or double-click:**
   ```bash
   index.html
   ```
